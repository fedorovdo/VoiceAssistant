# Приватность и передача данных

Этот документ описывает фактическое поведение VoiceAssistant. Он не является юридической гарантией.

## Микрофон и аудио

- Микрофон включается только после нажатия **Start / Старт**.
- Аудио делится на короткие чанки в памяти.
- Приложение не предназначено для сохранения аудиочанков на диск.
- При выбранном OpenAI STT чанки отправляются через локальный backend к настроенному провайдеру распознавания.

## Локальная справка

- После получения текста локальные ответы формируются из встроенного каталога знаний.
- Локальная справка не требует GPT-запроса.
- Контекст Live Assist, буфер фразы и очередь существуют в памяти renderer-процесса и очищаются при **Clear** или завершении приложения.

## GPT и гибридный режим

- В режимах GPT-only и Local knowledge + GPT распознанный текст может отправляться в OpenAI для генерации ответа.
- В Local-only режиме GPT не вызывается для ответа, но микрофонное распознавание через OpenAI STT все равно отправляет аудиочанки на транскрипцию.

## API-ключ

- Пользователь сам вводит и контролирует свой OpenAI API key.
- Проект не содержит центрального сервера для сбора пользовательских API-ключей.
- Ключ хранится локально в настройках приложения.
- Не публикуйте ключ в issue, логах, скриншотах или сообщениях.

## Стоимость

Использование OpenAI transcription и GPT может приводить к расходам у провайдера согласно тарифам вашего аккаунта.
