# Release Screenshots

Add release screenshots here before publishing a public GitHub Release. Do not fabricate screenshots; capture them from the current application build.

Required screenshots:

- Main Live Assist interface.
- Manual mode with the Ask button visible.
- Settings dialog.
- Local knowledge answer with source label.
- GPT answer with source label.
- Vertical layout.

Recommended capture notes:

- Use the Windows portable build intended for release.
- Avoid showing real API keys, private meeting text, or private audio device names.
- Prefer Russian and English examples when possible.
- Keep filenames descriptive, for example `live-assist-ru.png` or `settings-en.png`.
