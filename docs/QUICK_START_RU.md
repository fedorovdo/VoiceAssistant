# Быстрый старт VoiceAssistant для Windows

VoiceAssistant — локальный помощник для технических обсуждений. Он помогает быстро понимать технические фразы, вопросы и команды во время разговора, но не является универсальным сервисом расшифровки встреч.

## 1. Скачать

Скачайте портативный файл `VoiceAssistant-0.2.0-x64.exe` со страницы GitHub Releases:

`https://github.com/OWNER/VoiceAssistant/releases`

Установка не нужна. Файл можно положить в любую удобную папку.

## 2. Первый запуск и SmartScreen

Сборка пока не подписана сертификатом. Windows SmartScreen может показать предупреждение о неизвестном издателе.

Запускайте файл только если вы доверяете источнику загрузки и проверили SHA-256 из релиза.

## 3. Настройки API-ключа

Откройте **Settings / Настройки** и добавьте OpenAI API key, если нужны:

- распознавание речи через микрофон;
- GPT-ответы;
- GPT-обогащение локального ответа в гибридном режиме.

Не публикуйте и не отправляйте свой ключ в issue или логи.

## 4. Микрофон

1. Откройте настройки.
2. Нажмите **Request microphone permission / Запросить разрешение микрофона**.
3. Выберите аудиоустройство.
4. Нажмите **Refresh devices / Обновить устройства**, если список не обновился.

Имена устройств могут быть скрыты Windows/Electron до выдачи разрешения.

## 5. Manual mode

Manual mode подходит, когда вы хотите сами решать, когда задавать вопрос.

1. Выберите режим **Manual**.
2. Введите текст вручную или включите микрофонный STT.
3. Проверьте распознанный текст в верхней панели.
4. Нажмите **Спросить**.

В этом режиме приложение менее строго фильтрует фразу, потому что действие подтверждено пользователем.

## 6. Live Assist mode

Live Assist автоматически отвечает на завершенные технические вопросы и полезные фрагменты.

1. Выберите **Live Assist**.
2. Выберите STT provider: `mock`, `disabled` или `microphone`.
3. Нажмите **Start / Старт**.
4. Говорите технический вопрос или короткий запрос.

Live Assist использует буфер фразы, контекст темы, защиту от дублей и очередь запросов. Случайные или шумные фрагменты не должны стирать последний полезный ответ.

## 7. Источник ответа

- **Только локальная справка**: ищет ответ в встроенном каталоге и не вызывает GPT. После распознавания микрофона локальный ответ не требует GPT-запроса.
- **Локальная справка + GPT**: сначала показывает быстрый локальный ответ, затем может дополнить его GPT.
- **Только GPT**: пропускает локальную справку и требует API-ключ.

Важно: микрофонное распознавание пока использует OpenAI transcription, поэтому для реального STT нужен API-ключ и интернет даже в режиме локальных ответов.

## 8. Языки

- **Interface language** меняет язык интерфейса.
- **Answer language** задает язык ответов.

Например, интерфейс может быть русским, а ответы — английскими.

## 9. Локальная справка

Локальная справка работает из встроенного каталога знаний: Linux, Docker, Kubernetes, сети, Active Directory, Git, Proxmox и Samba.

Она не покрывает все возможные вопросы администратора, но быстро отвечает на частые команды и термины без GPT-вызова.

## 10. Остановка и очистка

- **Stop / Стоп** останавливает запись и активную обработку, но кратковременный контекст темы может сохраниться в памяти.
- **Clear / Очистить** удаляет распознанный текст, ответ, очередь, дубли, буферы и контекст.

Аудио не сохраняется на диск намеренно.

## Частые ошибки

### Backend port occupied during development

Если при разработке занят порт `127.0.0.1:8787`, выполните:

```powershell
npm run check:ports
npm run stop:dev
```

### Missing API key

Микрофонное распознавание и GPT-режим требуют OpenAI API key. Добавьте ключ в настройках.

### Microphone access denied

Проверьте разрешения Windows для микрофона и снова нажмите запрос разрешения в настройках.

### STT 502

Обычно это временная ошибка провайдера, сети или API. Проверьте интернет, API-ключ и повторите запись.

### Duplicate application instance

Если приложение уже запущено, второй экземпляр завершится с сообщением `VoiceAssistant is already running.`
