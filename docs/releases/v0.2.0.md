# VoiceAssistant 0.2.0 Release Notes

VoiceAssistant is a local technical discussion assistant for Windows. It helps explain technical questions, commands, and short technical fragments during live conversations.

## Highlights

- Portable Windows EXE with bundled local backend.
- Experimental microphone recording and OpenAI transcription.
- Manual mode and Live Assist mode.
- Local-only, Local knowledge + GPT, and GPT-only answer sources.
- Offline local knowledge packs for Linux, Docker, Kubernetes, networking, Active Directory, Git, Proxmox, and Samba.
- Russian and English interface.
- Vertical and horizontal layouts with resizable splitter.
- Bounded FIFO queue for Live Assist answer requests.

## Download

Download `VoiceAssistant-0.2.0-x64.exe` from GitHub Releases.

No installation is required. The executable is currently unsigned, so Windows SmartScreen may warn about an unknown publisher.

## SHA-256 Verification

PowerShell:

```powershell
Get-FileHash .\VoiceAssistant-0.2.0-x64.exe -Algorithm SHA256
Get-Content .\VoiceAssistant-0.2.0-x64.exe.sha256
```

The hash from `Get-FileHash` should match the hash in the `.sha256` file.

## Quick Start

1. Start `VoiceAssistant-0.2.0-x64.exe`.
2. Open Settings.
3. Add an OpenAI API key if microphone STT or GPT answers are needed.
4. Select a microphone.
5. Choose Manual or Live Assist mode.
6. Choose Local-only, Local knowledge + GPT, or GPT-only.
7. Press Start.

## Privacy Note

Local knowledge answers are generated locally after text is available. Microphone STT currently sends short audio chunks through the local backend to OpenAI when an API key is configured. GPT and hybrid answer modes may send recognized text to OpenAI. VoiceAssistant does not intentionally save microphone chunks to disk.

## Known Limitations

- Windows is the primary tested platform.
- Microphone recognition quality depends on speech clarity, microphone quality, and environment.
- OpenAI transcription requires internet access and a valid API key.
- The local knowledge catalog is curated and does not cover every administration question.
- Experimental STT may split or misrecognize technical phrases.
- The portable executable is currently unsigned.
